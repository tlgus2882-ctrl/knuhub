# MVP 스펙

`과제공유플랫폼_기획.md`의 MVP 범위를 2026-10-07 grilling 세션에서 구체화한 결과. 용어는 [GLOSSARY.md](../GLOSSARY.md)를 따른다. 목표 완료 시점: 2026년 12월 초.

## 기술 구성

- Next.js (App Router) + TypeScript + Tailwind CSS, `main`에서 새로 시작 (`wh` 브랜치는 사용하지 않음)
- Supabase: Auth, Postgres + RLS, Storage ([ADR-0001](adr/0001-supabase-as-backend.md))
- 코드 하이라이팅: Shiki / 배포: Vercel

## 가입·로그인

- `@kangnam.ac.kr` 메일만 가입 가능. 비밀번호로 가입하고 메일 인증 1회.
- 가입 입력값: 학번(학생만, 선택), 이름, 전화번호(필수), 개인정보 수집 동의(학번·이름·전화번호·연락처).
- 학번은 중복 불가, 가입 후 본인 수정 불가. 중복 시 "관리자에게 문의" 안내 → 관리자가 대시보드에서 조치.
- 전화번호는 본인과 관리자만 볼 수 있다. 작성자 카드·수강생 명단·연락처에 노출하지 않는다.
- 로그인 아이디: 학번 또는 학교 메일 + 비밀번호.
- 비밀번호 재설정: 가입한 학교 메일로 재설정 링크.

## 역할

- 모든 사용자는 학생으로 가입. 관리자가 Supabase 대시보드에서 교수로 승격 (관리자 페이지는 v2).
- 조교는 과목 안에서만 갖는 역할. 담당 교수가 지정.

## 과목

- 필드: 과목명, 학기(예: 2026-2), 분반. 개설한 교수 1명이 담당 교수, 조교는 여러 명.
- 초대 코드 입력 시 즉시 수강생으로 참여. 담당 교수는 수강생 내보내기, 초대 코드 재발급 가능.
- 수강생 명단: 이름·학번·학교 메일 표시. 과제별 제출 현황 표(제출 여부, 제출 시각).

## 과제

- 개인 과제만. 필드: 제목, 설명(마크다운, 채점 기준표도 자유 텍스트로 포함), 마감일, 첨부파일, 공개 범위.
- 공개 범위: 비공개 / 수강생 공개(기본값) / 학내 공개. 과제 생성 시 정하고 언제든 변경 가능.
- 마감일은 언제든 변경 가능.

## 제출물

- 학생·과제당 하나. 마감 전에는 재제출(덮어쓰기)·삭제 가능, 마감 후 불가. 지각 제출 없음.
- zip은 브라우저에서 풀어 파일별로 Storage에 저장. 제출물당 최대 20MB. `node_modules`, `.git` 등 자동 제외.
- 텍스트 파일은 코드 뷰어(파일 트리, 줄 번호, 하이라이팅), 바이너리는 다운로드 링크만.
- 열람: 마감 전에는 작성자 본인 + 담당 교수·조교. 마감 후에는 공개 범위에 따름. 항상 현재 마감일 기준으로 계산 (연장하면 다시 숨겨지고 재제출이 열림).

## 작성자 카드·연락처

- 이름과 학번은 항상 표시.
- 연락 수단(학교 메일, 오픈채팅 링크, GitHub 아이디) 중 사용자가 고른 것만, 연락처 공개 범위(전체 / 수강생 / 비공개)에 따라 표시.

## 리뷰

- 제출물을 볼 수 있는 사람은 누구나 작성 가능. 작성자 이름 표시 (익명은 v2).
- 작성자는 언제든 수정·삭제, 담당 교수는 자기 과목의 리뷰 삭제 가능.
- 마감 전 교수·조교가 남긴 리뷰는 제출물이 공개되면 함께 공개.

## 탐색·검색

- 학기 → 과목 → 과제 목록은 로그인한 모든 사용자가 열람. 제출물 목록은 공개 범위에 따름.
- 검색 대상: 과목명, 과제명, 학생 이름·학번. 볼 권한이 있는 결과만.

## 탈퇴

- 탈퇴 시 프로필, 제출물, 리뷰를 모두 삭제.
